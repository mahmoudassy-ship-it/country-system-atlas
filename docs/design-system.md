# Primary-screen design system

Concept: `design/system-atlas-primary-screen.png`

## Visual direction

An editorial civic-data atlas: calm, precise, and public-facing. The map is the primary visual object; supporting evidence uses open rails, lists, and charts instead of a bento grid.

## Tokens

- Background: true white `#ffffff`.
- Map field: cool gray-blue `#f5f9fc`.
- Ink: `#082650`.
- Muted ink: `#50647d`.
- Rule: `#d7e0e9`.
- Accent: mineral blue `#0767d8`.
- Selected map: deep blue `#0757bc`.
- Favorable: teal `#0a817d`.
- Adverse: terracotta `#e05b4f`.
- Missing: `#cdd4dc`.
- Radius: 6px controls, 8px compact panels; no oversized rounded containers.
- Shadows: none by default; use one-pixel borders and spatial hierarchy.

## Typography

- Editorial headings and country names: Newsreader, fallback Georgia.
- UI, data, labels, and body copy: Inter, fallback system sans-serif.
- Header brand: 24px/700.
- Country name: 44px/700 desktop.
- Section heading: 28px/650.
- Metric value: 16px/650 with tabular numbers.
- Controls: 13–14px/550.
- Captions: 11–12px/500.

## Component inventory

- Quiet application header with globe/compass mark.
- Country search combobox.
- SVG world map with hover, selected, unavailable, and keyboard-focus states.
- Metric selector and map legend.
- Selected-country profile rail.
- Underlined section tabs.
- Metric list rows with value, period, sparkline, and comparable change.
- Sources and methodology action.
- Ten-year trend chart.
- Peer dot plot.
- Source-detail drawer.

## Icon inventory

Icons use a consistent 1.5px outline treatment: search, globe, zoom in/out, information, clock, document, chevron, trend up/down, and close.
